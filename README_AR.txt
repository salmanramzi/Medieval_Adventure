حراس المملكة — لعبة ويب 3D

افتح index.html عبر خادم HTTP أو HTTPS، وليس file://.
مثال على الكمبيوتر: python -m http.server 8000 ثم افتح http://localhost:8000
اللعبة تحتاج إنترنت لتحميل مكتبة Three.js من jsDelivr. جميع نماذج الشخصيات والمباني موجودة داخل ZIP.
التحكم: عصا اللمس وزر السيف، أو WASD و Space.
لـ Lens Web: ارفع محتويات المجلد حسب طريقة الاستضافة المسموحة، وتأكد من دعم CDN والملفات ثلاثية الأبعاد.
